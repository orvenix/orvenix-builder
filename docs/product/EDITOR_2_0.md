# Editor Orvenix 2.0

## Objetivo

Permitir que una persona sin experiencia cree y publique un sitio profesional sin depender de tutoriales extensos ni conocimientos técnicos.

## Principio central

Simple para empezar. Potente para crecer.

## Experiencia básica

El usuario debe poder:

- elegir una estructura inicial;
- agregar secciones;
- editar textos;
- cambiar imágenes;
- mover y duplicar contenido;
- guardar automáticamente;
- revisar una vista previa;
- publicar.

## Acciones principales visibles

- Secciones.
- Diseño.
- Archivos.
- Mentor.
- Más opciones.
- Vista previa.
- Publicar.

## Funciones avanzadas

Deben permanecer fuera del flujo inicial:

- capas;
- variables;
- bindings;
- código;
- animaciones avanzadas;
- controles técnicos de layout;
- ajustes internos;
- herramientas de desarrollo.

## Modelo de interacción

### Contenido

Se edita directamente sobre la página siempre que sea posible.

### Diseño

Se configura desde un inspector contextual con pocas opciones principales.

### IA

Aparece mediante acciones contextuales y explicaciones breves.

### Movimiento

Las secciones pueden reorganizarse de forma visual y predecible.

### Guardado

Debe ser automático y comunicar claramente su estado.

## Criterio de éxito

Una persona que nunca ha usado un constructor debe poder crear una página completa y entender cómo modificarla sin pedir ayuda externa.
