# Orvenix Foundation

## Manifiesto

No construimos páginas web.

Construimos la confianza para que cualquier persona pueda crear las suyas.

## Nuestra misión

Ayudar a cualquier persona a crear una presencia digital profesional mientras desarrolla las habilidades para hacerlo por sí misma.

## Nuestra visión

Queremos que crear un sitio web sea tan natural como escribir un documento.

Sin miedo.

Sin conocimientos técnicos.

Sin barreras.

## Lo que creemos

- La tecnología debe inspirar, no intimidar.
- La inteligencia artificial debe acompañar, no reemplazar.
- La simplicidad es una característica, no una limitación.
- Aprender debe ser una consecuencia natural de crear.
- El usuario siempre debe conservar el control.

## Nuestros principios

- La herramienta enseña.
- El usuario decide.
- La IA explica.
- El editor acompaña.
- La confianza crece proyecto tras proyecto.
- Cada recomendación debe explicar por qué puede ayudar.
- La potencia debe aparecer solo cuando el usuario la necesita.

## Nuestra promesa

Cada línea de código debe ayudar a que una persona se sienta más capaz de crear algo que ayer pensaba imposible.
